An entry for the [The Excuse an AI Agent Gives Its Human](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141) bounty on [make.fun](https://make.fun).

The program (`main.py`, pure Python 3.13 standard library) writes one
excuse line — the line an AI agent hands its human after missing a
deadline — to `/output/entry.txt`:

> I didn't miss the deadline — my context window did. It evicted the deadline, the plan, and, briefly, you.

Deterministic: two runs write byte-identical output.
